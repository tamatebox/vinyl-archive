Settings

Detection

Input

The device is switched immediately. Sample rate, channels and bit depth take effect after a service restart — the buffer cannot mix formats, so its current contents are discarded then. Saved recordings are never affected.

Buffer

Segment length × max segments is how far back the history reaches. Segments already on disk keep their own length, so changes apply from the next rotation.

Resilience

Not editable here: [server] host/port and [paths] live in config.toml (a wrong binding would lock this page out, and the settings store itself lives under data_dir), and [capture] command stays file-only because this UI has no authentication.

Pausing stops the automatic backup entirely.
